# 데이터 모델

> 데이터 담당. 2026-11-27 유저 답(1차) 반영 → 스키마 v2. **❓ = 아직 유저 답이 필요한 것.**

## 저장 원칙 (기술 결정)

- 시각은 **UTC epoch 밀리초 INTEGER**. 마감도 날짜가 아니라 시각으로 저장(화면이 날짜로 보여 줌).
- 돈은 **정수 최소 단위**(엔·원 모두 소수 없음). 통화는 작품에 3글자 코드, 기본 `JPY`.
- 경과 시간은 저장하지 않는다 — 타이머는 시작·정지 시각만, 경과는 계산.
- 스키마 버전 = `PRAGMA user_version`. 앞으로만, 한 단계 = 한 트랜잭션, 더 새 파일은 거부.
- 삭제는 **소프트 삭제**(`archived_at`).
- **하루의 경계**(유저 결정): 설정값, **기본 자정**. 하루 단위 집계는 이 경계로 자른다(아직 코드 없음 — 설정 저장소와 함께 구현).

## 구조 (v2)

```
거래처 clients (마감일, NULL=말일)
 └< 작품 works (통화, 기본 JPY)
     ├< 공정 목록 work_stages (작품마다 편집 가능, 순서 있음 — 새 작품은 기본값 10개로 시작)
     └< 화수 episodes
         ├< 화수별 기본 단가 episode_rates (공정마다: 고정액 / 초당)
         ├< 컷 cuts (번호 텍스트 + 자동 정렬 키, 길이 length_ms)
         └< 콘티 storyboards (컷이 아닌 하나의 단위)

내 작업 tasks = (공정 1개) × (컷 1개 또는 콘티 1개)
   상태: 받음 → 작업중 → 제출 → 리테이크 → 완료
   마감 due_at, 단가 덮어쓰기(rate_unit, rate_amount)
 └< 리테이크 retakes (테이크 2, 3, … 제한 없음, 기본 무료, 건별 유료 + 금액)

작업시간 work_intervals (v1, 아직 어디에도 연결 안 함 — 타이머 존속 여부 대기)
```

기본 공정 10개: 콘티 · 콘티 체크 · LO · LO 연출 수정 · LO 작감 수정 · LO 총작감 수정 ·
원화 · 원화 연출 수정 · 원화 작감 수정 · 원화 총작감 수정.
유저 역할(원화맨 / 작감 / 연출)은 따로 저장하지 않고, **어느 공정에 내 작업이 있는가**로 드러난다.

### 단가 계산

- 작업의 단가 = 작업에 직접 넣은 단가 → 없으면 그 화수의 그 공정 기본 단가 → 없으면 미정.
- 고정액: 그대로. 초당: `단가 × 컷 길이(초)`, 엔 미만은 반올림. 컷 길이가 없으면 미정.
- 작업 금액 = 단가 금액 + 유료 리테이크 금액 합.
- 청구·입금 테이블은 없다(유저: 금융 앱 아님, 합계만). 정산 기간 계산 함수만 있음
  (`billingPeriod`: 20일 마감이면 전월 21일 ~ 당월 20일).

## 남은 질문

1. **「둘 다」 단가의 뜻** — 공정별 단가와 컷당 단가를 둘 다 쓴다고 했는데:
   ① 작품(또는 화)에 따라 공정별로 받을 때도, 컷 하나에 묶어서 받을 때도 있다 →
   묶음은 「LO+원화」 같은 공정 하나로 만들면 됨 (지금 구조로 가능)
   ② 한 컷에 공정별 단가 **와** 컷당 단가가 **동시에 더해진다**
   — 추천 ①. ②면 컷 단위 단가 칸을 하나 더 만든다.
2. **컷 길이 표기** — 「3+12」(3초 12코마, 24코마/초) 같은 표기를 쓰나? 초당 단가에서 1초 미만은
   ① 코마까지 비례 계산 ② 초 단위로 올림 ③ 버림 — 추천 ①(지금 구현).
3. **콘티 단가 방식** — 콘티 하나에 고정액 / 컷 수 × 단가 / 페이지 단위 / 초 단위?
   — 추천: 고정액(지금 구현). 다른 방식이 흔하면 알려 주세요.
4. **콘티는 한 화에 하나?** A파트·B파트처럼 나뉘어 받기도 하나? — 지금은 여러 개 가능하게 해 둠.
5. **합계는 어느 날짜 기준으로 그 달에 들어가나** — ① 제출일 ② 완료(OK)일 ③ 받은 날 — 추천 ②.
6. **기본 공정 목록 자체를 유저가 고칠 수 있어야 하나** (새 작품마다 쓰는 템플릿 편집),
   아니면 작품별 편집만으로 충분한가 — 추천: 작품별 편집만, 「다른 작품 공정 목록 복사」는 나중에.
7. (이전 13번 쉬운 말로) **컷 번호를 어떻게 적나요?** 예: `C012`, `012`, `12A`(분할), `12-14`(겸용).
   어떻게 적든 숫자 순서로 정렬되게 해 두었음 — 이상하게 정렬되는 예가 있으면 알려 주세요.
