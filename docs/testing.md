# 테스트 원칙과 감사 기록 (데이터 쪽: core · models · services · platform · controllers)

## 기준

- **Khorikov 『Unit Testing Principles』의 4기둥** — 회귀 보호 · 리팩터링 내성 · 빠른 피드백 · 유지보수성.
  구현 세부(내부 SQL 문자열 · private 순서 · 호출 횟수)를 핀하지 않고 **관찰 가능한 동작**을 본다.
  대역은 **관리되지 않는 의존**(사용자 파일 · 플랫폼 채널)에만. SQLite 는 관리되는 의존이라 실DB(메모리/임시 파일) 그대로.
  채널 테스트(`document_channel_test`)가 메서드 이름·인자를 확인하는 것은 네이티브와의 **계약**이라 예외가 아니다.
- **Google SWE Book** — 동작을 테스트, DAMP(읽히게) > DRY, 작은 테스트 중심.
- **Anicel 규칙** — 한 법은 **가장 싼 층에서 한 번만** 핀(중복 핀 금지). 「통과는 증거가 아니다 — 제품 코드를 끄면
  빨개지는지가 증거」 ⇒ 손 뮤턴트로 확인(아래). 뮤테이션은 커밋 뒤에, 되돌리기는 `cp` 왕복(`git checkout` 금지).

## 손 뮤테이션 (2026-11-28)

핵심 로직 46개 뮤턴트(조건 뒤집기 · 경계 ±1 · 리턴 바꾸기). **1차: 29 잡힘 · 17 생존** → 15개는 테스트 보강, 2개는 동등 뮤턴트.

| 생존 뮤턴트 | 처리 |
|---|---|
| `behind`: `remaining > 0 &&` 빼기 | 보강 — 남은 컷 0 은 지연 아님 |
| `dueSignal`: `days < 0` → `<= 0` | 보강 — 오늘 마감 = D-0 |
| `planSignal`: `slack < 0` → `<= 0` | 보강 — 계획 끝 = 마감일은 초과 아님 |
| `planSignal`: `toStart <= 0` → `< 0` | 보강 — 오늘 시작 예정 · 미착수 = 늦은 시작 |
| `PartGroup.waiting`: `isOpen` 빼기 | 보강 — 넘긴 컷은 대기 아님 |
| 레인 `fits`: 같은 날 끝/시작 | 보강 — 같은 날이면 다른 레인 |
| 정확 반올림 `+500` 빼기 | 보강 — 1.5초×3 = 5 |
| 범위 한도 `>=` → `>` · 일련 번호 한도 빼기 | 보강 — 한도 정확히 / 한도+1 |
| 시급: 시간 없는 작업 포함 | 보강 |
| 빠진 작업의 계획이 레인 차지 | 보강 |

## 의존 방향 (자동 검사)

`core < models < services < controllers` — 안쪽만 import. `platform/` 은 services 위 · ui 아래, flutter 는
`services` · `foundation` 까지. 이 다섯 층은 `ui/` · material · widgets · cupertino 를 import 하지 않는다.
예외 장부는 0개로 시작(`test/architecture/import_direction_test.dart` 의 `_ledger`).
